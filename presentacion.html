02 · Metodología

Estandarización presupuestal

El ANA presupuestaba varias fichas a costo total, incluyendo obras civiles (muros, diques) que exceden el alcance real de MVCS — limpieza y descolmatación de cauce. Se desarrolló una metodología para ajustar el presupuesto a lo que efectivamente se ejecuta.

03 · La Herramienta

El Visor de Intervenciones ante el FEN

Una plataforma web propia — HTML, CSS y JavaScript puro, sin servidor ni base de datos externa — que centraliza mapa, presupuesto, maquinaria y supervisores en un solo lugar. Capturas reales del sistema en producción.
